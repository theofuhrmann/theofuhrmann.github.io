# theofuhrmann.github.io

Source code for my personal website, live at [theofuhrmann.github.io](https://theofuhrmann.github.io).

Built with [Astro](https://astro.build) and deployed to GitHub Pages via GitHub Actions on every push to `main`.

## Local development

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # output to ./dist
```
